# Security policy

If you find a vulnerability, please report it privately through
[GitHub's vulnerability reporting](https://github.com/ulliiiiiiiii/ai-sandbox-guard/security/advisories/new)
instead of opening a public issue. I will get back to you as soon as I can.

Any way to get a network call past the guard counts, even one that needs an unusual
command. Please include the tool call that got through.

Fixes go into the latest release only.
